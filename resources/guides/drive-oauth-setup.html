NovelTrans Studio

Hướng dẫn cấu hình Google Drive OAuth

Làm theo từng bước để lấy Client ID, lưu trong app, rồi kết nối Drive. Client Secret không bắt buộc. Redirect URI phải đúng http://127.0.0.1:18766 (không dùng localhost).

Mở Google Cloud Console Mở Credentials

Trình tự

  1. Tạo / chọn project Google Cloud
  2. Bật Google Drive API
  3. Cấu hình OAuth consent screen
  4. Tạo OAuth Client ID kiểu Desktop app
  5. Redirect URI (quan trọng)
  6. Lưu Client ID trong NovelTrans
  7. Kết nối Drive trên tài khoản Google
  8. Khắc phục lỗi thường gặp

1 Tạo / chọn project

  1. Mở Google Cloud Console.
  2. Góc trên bên trái → chọn project hiện có, hoặc New Project.
  3. Đặt tên ví dụ NovelTrans Studio → Create.

2 Bật Google Drive API

  1. Menu APIs & Services → Library.
  2. Tìm Google Drive API.
  3. Bấm Enable.

3 OAuth consent screen

  1. Vào APIs & Services → OAuth consent screen.
  2. User type: chọn External → Create.
  3. Điền App name (vd. NovelTrans Studio), User support email, Developer contact.
  4. Scopes → Add or remove → thêm https://www.googleapis.com/auth/drive.file → Save.
  5. Nếu app đang Testing: thêm email Google của bạn vào Test users.
Tip Chỉ cần scope drive.file (file do app tạo/mở). Không cần full Drive.

4 Tạo Client ID — chọn Desktop app

  1. Vào APIs & Services → Credentials.
  2. Create Credentials → OAuth client ID.
  3. Application type: chọn Desktop app (không chọn Web application).
  4. Name: vd. NovelTrans Desktop → Create.
  5. Copy Client ID. Client Secret nếu có thì tuỳ chọn — app không bắt buộc.
Sai kiểu client = lỗi redirect_uri_mismatch Nếu lỡ tạo Web application, hoặc tạo lại Desktop app, hoặc thêm đúng redirect URI ở bước 5.

5 Redirect URI phải đúng chuỗi này

NovelTrans dùng loopback cố định. Dùng 127.0.0.1, không dùng localhost. Không thêm path (không /oauth2callback).

http://127.0.0.1:18766
Loại clientViệc cần làm
Desktop app (khuyến nghị) Google tự chấp nhận loopback. Không cần khai báo URI. Chỉ cần Client ID.
Web application Credentials → Edit client → Authorized redirect URIs → Add URI → dán đúng chuỗi trên → Save.
Đúng http://127.0.0.1:18766
Sai — sẽ lỗi 400 redirect_uri_mismatch
  • http://localhost:18766
  • http://127.0.0.1:18766/oauth2callback
  • Port khác (app cố định 18766)

6 Lưu trong NovelTrans Studio

  1. Mở app → Cài đặt → Google Drive.
  2. Dán Client ID → (tuỳ chọn) Client Secret → Lưu OAuth client.
  3. Thấy badge Đã cấu hình và dòng gợi ý Client ID đã lưu (dạng che).
Client ID “mất” trên form? Ô nhập để trống là bình thường. App đã lưu mã hóa — nhìn badge / “Đã lưu: xxxx…”. Muốn đổi thì dán Client ID mới rồi Lưu lại.

7 Kết nối Drive

  1. Vào Tài khoản Google.
  2. Thêm / đăng nhập tài khoản Gemini trong trình duyệt app (nếu chưa).
  3. Bấm Đã kết nối · Google Drive (Connect Drive).
  4. Trình duyệt hệ thống mở Google → đăng nhập → bấm Tiếp tục / Cho phép.
  5. Thấy trang “Drive đã kết nối” → quay lại app. Thẻ tài khoản hiện Drive đã kết nối.
  6. Nếu sau Tiếp tục trình duyệt báo không kết nối được tới 127.0.0.1:18766: copy URL trên thanh địa chỉ (có ?code=) → trong app mở mục Bấm Tiếp tục xong bị đứng… → dán URL → Hoàn tất bằng URL.

Khắc phục lỗi

Error 400: redirect_uri_mismatch

  • Client phải là Desktop app, hoặc Web đã thêm đúng http://127.0.0.1:18766.
  • Không dùng localhost / không thêm path.
  • Khởi động lại app sau khi sửa Credentials trên GCP (đôi khi cần vài phút).

access_denied / app chưa verified

  • Consent screen đang Testing → thêm email vào Test users.

Bấm Tiếp tục trên Google nhưng không hoàn tất

  • Nút Tiếp tục không phản hồi: cuộn xuống hết trang consent; thêm digimonday.group@gmail.com (email đang đăng nhập) vào Test users trên GCP nếu app đang Testing; thêm Privacy Policy URL trên OAuth consent screen (Google khuyến nghị, đôi khi chặn bước cuối).
  • Sau Tiếp tục, trình duyệt báo ERR_CONNECTION_REFUSED / không kết nối 127.0.0.1:18766: bình thường nếu firewall chặn loopback — copy URL có ?code= từ thanh địa chỉ → NovelTrans → Tài khoản Google → mục Hoàn tất bằng URL.
  • Trang lỗi “Đổi mã thất bại”: OAuth client kiểu Web thường cần Client Secret trong Cài đặt; hoặc chuyển sang Desktop app.
  • Kiểm tra Windows Firewall không chặn NovelTrans lắng nghe cổng 18766.

Port 18766 đang dùng

  • Đóng app/tool khác chiếm cổng, rồi Connect Drive lại.
